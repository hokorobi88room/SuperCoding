# 神の観察 (Deus Ex Vita)

> 生命を見つめる者へ。

『神の観察』は、**各個体が進化するニューラルネットの脳を持つ**人工生命シミュレータです。
あなたは数値を弄る管理者ではなく、天から世界を見下ろす**神**として、御業の手を差し伸べ、
いのちの進化・文化・文明が自ずと立ち上がるさまを観察します。

すべては WebGPU 上で駆動し、数千のいのちが同時に思考し、群れ、争い、育ち、還ってゆきます。
そこに正解はありません。あなたが世界に触れるたび、二度と同じにはならない歴史が刻まれます。

---

## 世界観

深い宇宙のような、深海のような場所。ここには二種類の存在が漂います。

- **糧(いのちの糧)** — 受動的な胞子。潮に流され、光合成でエネルギーを蓄えます。脳はありません。
- **いのち** — 神経進化する生命。小さな脳を持ち、感覚から行動を自ら決めます。
  草食から肉食まで食性は連続的に変化し、体格・速さ・社会性・文化も世代を経て移ろいます。

世界はトーラス(上下・左右がつながった環)です。端は存在せず、いのちはどこまでも巡ります。

## 操作 — 神の御業

画面左端の御業パレットから道具を選び、キャンバスをなぞって世界に介入します。
ホイールで御手の広さ、スライダーで御力の強さを調整できます。

| 御業 | はたらき |
|---|---|
| **観察 (OBSERVE)** | 何もせず、静かにいのちの営みを見つめる。 |
| **恵み (BLESS)** | なぞった水面に糧を降らせ、いのちを養う。 |
| **天罰 (SMITE)** | 範囲のいのちを滅する。淘汰の圧を与える。 |
| **誘い (BECKON)** | いのちを御手へ引き寄せる引力。 |
| **忌避 (REPEL)** | いのちを御手から遠ざける斥力。 |
| **渦 (MAELSTROM)** | 渦を巻き起こし、群れを大きく攪拌する。 |
| **障壁 (BARRIER)** | 越えられぬ壁を描き、地形をつくる。 |
| **消去 (ERASE)** | 描いた障壁や潮流を消し去る。 |
| **潮流 (CURRENT)** | なぞった向きへ、いのちを運ぶ流れを描く。 |

### キーボード

| キー | 動作 |
|---|---|
| `Space` | 一時停止 / 再開 |
| `G` | 創世(世界を作り直す) |
| `1`〜`9` | 御業を切り替え |
| `[` `]` | 御手の広さを増減 |

### そのほかの設定

- **速度** … 時間の流れを 0.25〜4 倍に。神は時の速さを司ります。
- **文明** … 建造行動を解禁/封印する段階ゲート。解禁するといのちが世界に痕跡を刻みはじめます。
- **画質** … 軽量 / 標準 / 荘厳。マシンに合わせてブルームや残像の強さを変えます。
- **音** … 生命の営みに呼応する生成アンビエントの ON/OFF と音量。

## いのちを読み解く

- **系譜パネル**(右)には、生きているいのちの平均形質が並びます。
  食性(草食⇄肉食)・攻撃性・社会性・速さ・文化・体格。世界の性格が一目で分かります。
- **年代記**(下)には、繁栄・大量死・絶滅の危機・肉食の台頭・部族の誕生・文明の夜明けといった
  創発イベントが、神の視点で綴られる一行の叙事詩として流れていきます。
- **部族**は最大 32 の識別色で描き分けられます。似た文化(ミーム)を持つ群れが同じ色に染まります。

## 技術解説 — なぜ「進化」するのか

このシミュレータには、あらかじめ書き込まれた「賢い行動ルール」がありません。
賢さは、世界の中で**自然淘汰と突然変異によって発見される**ものです。

### 1. 神経進化する脳

いのち一体一体が、固定トポロジの小さな多層パーセプトロン(MLP)を脳として持ちます。

- **入力(16)** … 自分のエネルギーと年齢、最寄りの糧・他個体への方向と近さ、血縁度、
  近傍の密度と平均進行方向、そして信号場から読み取る文化フェロモンと危険痕跡、内部時計。
- **中間層(16)** → **出力(8)** … 操舵、採餌、繁殖、攻撃、信号放出、ミーム変調、速度調整。
- 前向き計算は `h = tanh(W1·x + B1); o = tanh(W2·h + B2)`。すべて GPU 上で並列に走ります。

脳の重み(1体あたり 408 個)は、**繁殖のたびに親からコピーされ、微小なガウス変異**を受けます。
賢く振る舞えた個体ほど長く生き、多く子を残す——それだけで、世代を追うごとに行動が洗練されていきます。
狩りを覚える系譜、群れて身を守る系譜、糧の匂いを追う系譜。誰も設計していない戦略が立ち現れます。

### 2. 信号フェロモン場と文化の創発

世界には、いのちとは別に **信号場**(格子状のフェロモン層)が重なっています。

- **文化チャンネル** … いのちが脳の出力で放出するフェロモン。仲間の目印・縄張りの匂いになります。
- **食料の匂い** … 糧が放つ拡散信号。遠くの糧を嗅ぎつける手掛かり。
- **危険痕跡** … 死や捕食が起きた場所に沈着する匂い。危険を学ぶ材料になります。

信号場は毎フレーム**拡散し、減衰**します。放出と拡散のせめぎ合いから、フェロモンの「道」や
「縄張り」が自ずと描かれ、これが背景に立ち上がる文化の地図となります。

### 3. ミームの水平伝播

各個体は、遺伝子とは別に **ミームベクトル**(文化的な内部状態)を持ちます。
近くにいる元気な個体のミームへ少しずつ引き寄せられる——つまり**親から子へ縦に**だけでなく、
**個体から個体へ横に**伝わります。血縁度が高いほど伝わりやすく、似た心が引き合います。

この水平伝播が、遺伝とは独立した速さで**方言や流行**を広げ、群れを **部族** に分化させます。
系譜(血のつながり)と部族(文化のまとまり)は必ずしも一致しません。そこに社会の複雑さが生まれます。

### 4. 文明ステージ

文明を解禁すると、余剰のエネルギーを持ついのちが、自らの居る場所に**建造物を沈着**させます。
建造物は緩やかに減衰しつつ蓄積し、世界に人工の秩序——巣や集落の痕跡——を刻みます。
ただ生き延びるだけの世界から、何かを遺そうとする世界への移行です。

## 実装メモ

- TypeScript + Vite + WGSL。外部ライブラリ依存なし。描画・計算はすべて WebGPU。
- 計算は GPU のコンピュートパスで完結します(空間ハッシュ・脳の前向き計算・信号拡散・繁殖・淘汰)。
- 統計は少数の個体を CPU へ読み戻して集計し、ミームを軽量クラスタリングして部族数を推定します。
- 対応ブラウザ … WebGPU 対応の Chrome もしくは Edge の最新版。
