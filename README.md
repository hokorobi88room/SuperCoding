# 原初の海 — Primordial Sea

WebGPU のコンピュートシェーダで駆動する、**10万体規模の進化する生態系シミュレーション**です。
藻(食料)→ 小魚(被食者)→ 捕食魚 の三栄養段階が、あなたのブラウザの GPU 上で生まれ、群れ、狩り、繁殖し、そして絶える。個体はそれぞれ遺伝子を持ち、繁殖のたびに突然変異する。誰も設計していない群れの渦や捕食の均衡が、ただの数式から立ち現れるさまを眺めるための箱庭です。

深海の発光生態系をイメージした HDR 加算合成の描画で、無数の生き物が光の粒となって漂います。マウスひとつで餌をまき、海流を描き、岩を積み、恐怖を与えて、生態系の運命に干渉できます。

- スタック: TypeScript + Vite(Deno 経由)/ 外部ライブラリ依存なし / UI は日本語
- 描画・計算はすべて WebGPU。CPU はオーケストレーションと少量の統計リードバックのみ

---

## 動作環境

WebGPU に対応したブラウザが必要です。

- **Chrome / Edge 最新版**(Windows・macOS・Linux)を推奨
- WebGPU が無効な場合、起動画面にその旨が表示されます

GPU 上で毎フレーム十数万体を処理するため、ディスクリート GPU または新しめの内蔵 GPU を推奨します。

---

## 起動方法

[Deno](https://deno.com/) がインストールされていれば、追加のグローバルツールは不要です。

```sh
# 依存関係(vite / typescript / @webgpu/types)を取得
deno install

# 開発サーバを起動(既定で http://localhost:5173 が開きます)
deno task dev
```

その他のタスク:

```sh
deno task build      # 本番ビルド(dist/ を生成)
deno task preview    # ビルド結果をローカルで確認
deno task typecheck  # 型検査(tsc --noEmit)
```

起動したら、ブラウザで表示された URL を開いてください。数秒で海が満たされ、生き物が動き出します。

## 操作説明

画面左端の縦ツールバーからツールを選び、海の上でドラッグやクリックをして干渉します。ホイールでブラシ半径、縦スライダーでブラシ強度を変えられます。

### ツール(全9種)

| ツール | はたらき |
|---|---|
| 観察 | 何も干渉せず、ただ海を眺めます。 |
| 餌まき | ドラッグした場所に藻の胞子をまき、食料を供給します。 |
| 引き寄せ | 範囲内の生き物をカーソルへ引き寄せます。 |
| 押し出し | 生き物をカーソルから押し離します。 |
| 渦 | カーソルを中心に渦を起こし、群れを巻き込みます。 |
| 恐怖 | カーソルを仮想の捕食者とみなし、小魚を逃げ惑わせます。 |
| 岩 | 障害物(岩)を描いて海の地形をつくります。生き物は岩を避けます。 |
| 消しゴム | 描いた岩や海流を消し去ります。 |
| 海流 | ドラッグした向きへ海流を描きます。生き物は流れに乗って運ばれます。 |

右側のパネルでは、種ごと(光藻・銀鱗・紅牙)のパラメータをスライダーで調整できます。速度・視野・繁殖閾値・突然変異の強さ・環境収容力などを変えると、生態系の均衡が大きく揺れ動きます。プリセットのカードを選べば、あらかじめ用意した世界を一気に読み込めます。

下部中央には種別の個体数チャートが流れ、生態系の盛衰をリアルタイムで追えます。いずれかの種が絶滅すると、画面にその報せが表示されます。

## 三つの種

- **光藻(ひかりも)** — 光を食んで漂う原初の緑。操舵はせず海流に流されながら、光合成でエネルギーを蓄えて分裂・増殖する。海のすべての命の礎。
- **銀鱗(ぎんりん)** — 群れをなして舞う銀の小魚。分離・整列・結合の三規則(ボイド)で群泳しつつ藻を食み、視野に紅牙が入れば散り散りに逃げまどう。
- **紅牙(こうが)** — 深海を統べる紅の狩人。同族とは距離を取りながら、銀の群れの重心と最寄りの一匹を追って狩る。十分に蓄えれば繁殖する。

## 技術解説

このシミュレーションの要点は、**個体の状態も、その生死も、繁殖も、すべてを GPU 上で完結させる**ことにあります。CPU は毎フレームのオーケストレーションと、数フレームおきの統計リードバックだけを担当します。これにより 10万体規模でもインタラクティブなフレームレートを保ちます。

### WebGPU コンピュートによる並列シミュレーション

各エージェントは 48 バイトの構造体(位置・速度・遺伝子4値・エネルギー・年齢・種別・乱数シード)としてストレージバッファに格納されます。バッファは最大 131072 体ぶんを常に確保し、生死に応じてスロットを再利用します。

1フレームは複数のコンピュートパス(ワークグループサイズ 256)を順に実行して進みます。

1. **spawn** — CPU が積んだスポーン要求を処理し、フリーリストから空きスロットを取り出して新しい個体を書き込む。
2. **clearGrid** — 空間ハッシュのセルカウンタと、種別個体数・遺伝子合計のカウンタを 0 に戻す。
3. **buildGrid** — 生存個体を位置からセルに割り当て、空間ハッシュを構築する。
4. **behavior** — 近傍を探索して操舵を決め、移動・捕食・エネルギー収支を計算する。読み側バッファから書き側バッファへ書き込む(ping-pong)。
5. **death** — エネルギー枯渇・寿命・被食のフラグを見て、死んだ個体をフリーリストへ回収する。
6. **birth** — エネルギーが繁殖閾値を超え、周囲が過密でない個体を確率的に繁殖させる。子は親のコピーに突然変異を加えたもの。
7. **census** — 種別の生存数と遺伝子合計を集計する。

ワールドは上下左右がつながった**トーラス**です。距離計算はつねにラップ距離(`d -= round(d / world) * world`)を用い、端で群れが不自然に途切れないようにしています。

### 空間ハッシュによる近傍探索

10万体それぞれが近傍を素朴に総当たりすれば計算量は爆発します。そこでワールドを 12.5 ワールド単位のセル(128×72=9216 セル)に分割し、各セルに含まれる個体のインデックスを毎フレーム再構築します(**buildGrid** パス、`atomicAdd` でセル内スロットを確保)。

**behavior** パスでは、各個体は自分のセルとその周囲の 3×3(視野が広ければ 5×5)セルだけを走査すれば十分な近傍が得られます。これにより近傍探索が実質的に定数時間となり、群れの規模に対して計算がスケールします。

### GPU 上のライフサイクル管理

個体の生成と消滅は、**フリーリスト**と**アライブフラグ**で管理します。

- **aliveFlags**: 各スロットの状態(0=空き / 1=生存 / 2=今フレーム死亡)を持つアトミック配列。
- **freeList**: 空きスロットのインデックスを積んだスタック。先頭位置はアトミックカウンタ。繁殖やスポーンは `pop`(先頭を減らす)、死亡回収は `push`(先頭を増やす)で行います。

捕食は、被食者のフラグを `atomicCompareExchangeWeak(flags, 1, 2)` で「生存→死亡」に置き換えることで実現します。アトミック操作なので、同じ獲物を複数の捕食者が同時に狙っても二重取りは起きません。死亡パスがフラグ 2 のスロットをフリーリストへ返し、次のフレームで別の新しい命として蘇ります。

種別個体数・出生数・死亡数・捕食数・平均遺伝子といった統計は専用のカウンタバッファに集計し、数フレームおきに 1 回だけ CPU へ非同期リードバック(`mapAsync`)します。GPU→CPU の同期を最小限に抑えることで、描画の停止を招かずに HUD やチャートを更新できます。

### 進化システム

各個体は 4 つの遺伝子 **速さ・視野・体格・警戒心**(それぞれ 0〜1)を持ち、これらが実際の能力へ写像されます。

- **速さ** → 最高速度と加速力を増減させる。ただし代謝コストは速さの二乗で効くため、速い個体ほど燃費が悪いというトレードオフがある。
- **視野** → 近傍探索の半径を増減させる。
- **体格** → 捕食半径を広げる一方、代謝コストも増やす。
- **警戒心** → 捕食者からの逃走の強さを増減させる。

繁殖のたびに、子の遺伝子は親の値へ突然変異(`gene += (rand-0.5) * 2 * mutation`)を加えたものになり、0〜1 にクランプされます。エネルギー収支・繁殖・寿命という淘汰圧のもとで、有利な遺伝子を持つ個体が生き残って増えるため、**誰も設計していない適応が世代をまたいで自発的に進化**します。捕食圧が高い海では警戒心の高い小魚が、食料の乏しい海では燃費のよい遅い個体が優勢になる——といった変化を、平均遺伝子の表示で追うことができます。

パラメータやプリセットを変えれば、この淘汰圧そのものを手で捻じ曲げられます。安定した均衡、爆発的な増殖、破滅的な絶滅——同じ数式が描く無数の海を、心ゆくまで観察してください。
